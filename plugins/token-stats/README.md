# Token & Cache Stats (`token-stats`)

为 Antigravity 提供极简的对话 token、缓存命中率与模型/工具耗时统计。

## 包含两部分

1. **对话内每轮结束摘要（Hook）**
   - 中间工具调用步骤完全静默，**只在每轮最终回复后注入 1 条**精简统计：本轮总量、模型、缓存命中率、未缓存输入 / 缓存读取 / 输出、模型与工具用时，以及会话累计与右侧面板快捷入口。
2. **右侧边栏可视化面板（Sidecar UI：`Token Stats`）**
   - 自动绑定当前对话并实时刷新，**0 模型上下文占用**。
   - **顶部简易条**：`N 轮 M 步 · tok/s` 与 `总用量 · 缓存命中 %`，点击分别弹出「会话统计（耗时/速度/上下文）」与「会话用量（缓存读写明细）」弹窗。
   - **逐轮列表 + 详情弹窗**：每轮一行，点击弹出键值详情卡片（含本轮各 Step 明细与缓存未命中高亮）。

## 命令行复盘

```powershell
python plugins/token-stats/scripts/token_stats.py --file "<transcript.jsonl路径>"
```
