# Token & Cache Stats (`token-stats`)

为 Antigravity 提供极简的对话 token、缓存命中率与模型/工具耗时统计，并自动递归聚合子智能体（`invoke_subagent`、多层嵌套子代理及 `swarm`）用量。

## 包含两部分

1. **对话内每轮结束摘要（Hook）**
   - 中间工具调用步骤完全静默，**只在每轮最终回复后注入 1 条**精简统计：本轮总量、模型、缓存命中率、未缓存输入 / 缓存读取 / 输出、模型与工具用时，以及会话累计与右侧面板快捷入口。
   - 若本会话派发了子智能体（含嵌套子代理与 swarm worker），表格会自动追加「**子代理**」与「**总计**」两行；未调用子智能体时保持原有极简表格。
2. **右侧边栏可视化面板（Sidecar UI：`Token Stats`）**
   - 自动绑定当前对话并实时刷新，**0 模型上下文占用**；联合 ETag 同步监听主对话与全部子孙对话日志，主对话等待子智能体运行期间也能实时看到子智能体 token 增长。
   - **顶部简易条与总览卡片**：存在子智能体时默认展示「总计（含子代理）」，支持一键切换「总计 / 主对话」，并在总览卡片下方展示主对话与子代理拆分条。
   - **子智能体用量列表与下钻弹窗**：按嵌套层级展示每个子智能体的活跃状态、角色/类型、步数、总用量、缓存命中率与耗时；点击可查看该子智能体的步数明细与下级子代理。
   - **逐轮列表 + 详情弹窗**：每轮一行，派发过子智能体的轮次会附带子代理用量徽章，点击弹窗可直接下钻查看关联子智能体。

## 命令行复盘

```powershell
python plugins/token-stats/scripts/token_stats.py --file "<transcript.jsonl路径>"
```
